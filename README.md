## Hand Tracking Ball Game
Este é um jogo simples desenvolvido em Python, utilizando OpenCV e Mediapipe para rastreamento de mãos. O objetivo do jogo é manter uma bolinha "no ar" utilizando a palma da mão. A bolinha cai da parte superior da tela, e o jogador deve "rebater" a bolinha usando a palma da mão, fazendo o máximo de pontos possíveis.

## Funcionalidades
Rastreamento de Mãos: Utiliza a biblioteca Mediapipe para detectar e rastrear a posição das mãos em tempo real.
Interação com a Bolinha: O jogador interage com a bolinha, rebatendo-a com a palma da mão. A bolinha é lançada de volta para cima a cada toque bem-sucedido.
Pontuação: O jogo mantém o controle do número de toques (pontos) e exibe a melhor pontuação alcançada durante a sessão.
Início do Jogo: Pressione a tecla 'b' para iniciar a queda da bolinha.
Encerramento do Jogo: Pressione a tecla 'q' para sair do jogo.
